🏪 Votre Boutique

Application open source de gestion de vente pour Google Sheets — stock, ventes, clients, fournisseurs, commandes.

⚡ Installation en 5 étapes

  1. Créez un nouveau Google Sheets vide (sheets.new).
  2. Menu Extensions → Apps Script.
  3. Supprimez le contenu de Code.gs, puis cliquez sur Copier le code ci-dessous et collez-le. Enregistrez 💾.
  4. Rechargez la feuille : le menu 🏪 Votre Boutique apparaît. Cliquez sur ⚙️ Initialiser l'application et acceptez les autorisations Google.
  5. Utilisez ensuite Installer les déclencheurs (une seule fois).

⬇️ Télécharger VotreBoutique.gs

✨ Fonctionnalités

  • Tableau de bord : KPI, top produits, classements, alertes de stock
  • Produits avec code unique, prix d'achat = prix fournisseur le plus élevé
  • Ventes avec client (liste ou saisie, sinon « Client Passager »), annulation de vente
  • Clients et fournisseurs, comparaison des prix par fournisseur (🥇 meilleur prix)
  • Commandes fournisseur avec panier, bon de commande à imprimer ou en PDF
  • Recherche par code ou désignation (sans tenir compte des accents)
  • Rapports mensuels et suivi journalier

ℹ️ Important

Le fichier .gs n'est pas un site web : il ne s'exécute que dans Google Sheets, sur votre propre compte Google. Vos données restent dans votre feuille.

Projet open source — libre d'utilisation et de modification.
